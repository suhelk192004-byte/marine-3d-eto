MARINE 3D — ETO Explorer prototype

RUN:
1. Extract ZIP.
2. Open folder in VS Code.
3. Use Live Server → Go Live.
4. Internet is needed for Three.js and the optional exterior GLB.

FIX: The startup screen now times out after 9 seconds. If the external GLB stalls, the built-in 3D ship appears automatically and the user can continue exploring.

Interior compartments and machinery are an authored educational schematic, not an exact ship GA/construction model.
